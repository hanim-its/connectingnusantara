Nusantara Data 1.0

Dashboard pertama akses internet tingkat provinsi

Nusantara Data 1.0 adalah prototipe pertama dashboard Connecting Nusantara. Dashboard ini memvisualisasikan 48 dataset BPS tentang akses internet tingkat provinsi untuk menunjukkan kesenjangan digital antarprovinsi di Indonesia.

Pelajaran untuk versi berikutnya

  • Baru sebagian kecil dataset BPS yang tervisualisasikan: 48 dari rencana awal sekitar 150 jenis dataset.
  • Tampilan dan fitur masih sederhana, dan dashboard belum diuji dengan pengguna ahli maupun masyarakat umum.

Keterbatasan ini menjadi dasar pengembangan Nusantara Data 2.0.

Pengembang

Dikembangkan bersama mahasiswa Departemen Sistem Informasi, Institut Teknologi Sepuluh Nopember. Terima kasih atas kontribusi mereka dalam pengumpulan data dan pembangunan prototipe pertama.
