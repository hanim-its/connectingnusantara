<p class="lead-p">Nusantara Data 1.0 adalah prototipe pertama dashboard Connecting Nusantara. Dashboard ini memvisualisasikan 48 dataset BPS
tentang akses internet tingkat provinsi untuk menunjukkan kesenjangan digital antarprovinsi di Indonesia.</p>

<section>
  <h2>Pelajaran untuk versi berikutnya</h2>
  <ul>
    <li>Baru sebagian kecil dataset BPS yang tervisualisasikan: 48 dari rencana awal sekitar 150 jenis dataset.</li>
    <li>Tampilan dan fitur masih sederhana, dan dashboard belum diuji dengan pengguna ahli maupun masyarakat umum.</li>
  </ul>
  <p>Keterbatasan ini menjadi dasar pengembangan <a href="../nusantara-data-2/">Nusantara Data 2.0</a>.</p>
</section>
